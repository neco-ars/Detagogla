# Тагоглица

Переводчик между русским (кириллицей) и собственным алфавитом **тагоглица**.

В проекте два приложения с GUI:

- **`tagoglate.py`** — прямой переводчик: русский → тагоглица
- **`detagoglate.py`** — обратный переводчик: тагоглица → русский

Оба используют один и тот же словарь соответствий — `translate.json`.

## Как это работает

`translate.json` хранит соответствие «кириллическая буква → символ(ы) тагоглицы». Прямой переводчик просто заменяет каждую букву русского текста по этому словарю.

Обратный переводчик строит из того же словаря обратное соответствие и разбирает текст **жадно, слева направо**, на каждом шаге ища самый длинный подходящий токен тагоглицы (это важно, потому что некоторые буквы кодируются несколькими символами, например «й» = «и» + доп. символ).

### Известные ограничения

- **«щ» и «ш»+«ъ» неразличимы.** В таблице «щ» кодируется как `u„`, что посимвольно совпадает с последовательностью «ш» + «ъ». Обратный переводчик всегда раскодирует это как «щ».
- **Смешение с латиницей.** Часть символов тагоглицы — обычные латинские буквы (`q`, `n`, `u`, `v`, `o`, `b`, `2` и др.). Если во входном тексте окажутся настоящие латинские буквы или английские слова, обратный переводчик ошибочно превратит их в кириллицу.
- Прямой переводчик приводит текст к нижнему регистру перед переводом, поэтому оригинальный регистр при обратном переводе не восстанавливается.

## Требования

- Python 3.8+
- Библиотека `customtkinter`

Установка зависимости:

```
pip install customtkinter
```

## Запуск

```
python tagoglate.py
python detagoglate.py
```

Файл `translate.json` (и `lt.ico`, если используется иконка) должен лежать в той же папке, что и `.py`-файл.

## Сборка в отдельное .exe-приложение

Через [PyInstaller](https://pyinstaller.org/):

```
pip install pyinstaller
pyinstaller --onefile --windowed --icon=lt.ico --add-data "translate.json;." tagoglate.py
pyinstaller --onefile --windowed --icon=lt.ico --add-data "translate.json;." detagoglate.py
```

Готовые `.exe` появятся в папке `dist/`. Флаг `--add-data` встраивает `translate.json` внутрь исполняемого файла, так что отдельно таскать JSON вместе с exe не нужно.

Если команда `pyinstaller` не находится в терминале, используйте:

```
python -m PyInstaller --onefile --windowed --icon=lt.ico --add-data "translate.json;." tagoglate.py
```
